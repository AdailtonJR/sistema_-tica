# Sistema da Ótica V2

Projeto inicial do sistema de gestão de uma ótica em Python.

## Tecnologias
- Python 3
- CustomTkinter
- SQLite

## Como executar no VS Code

Abra o terminal na pasta do projeto e execute:

```bash
pip install -r requirements.txt
python main.py
```

No Windows, se necessário:

```bash
py -m pip install -r requirements.txt
py main.py
```

## Login inicial

Usuário: `admin`  
Senha: `1234`

O banco será criado automaticamente em:

`banco/otica.db`
